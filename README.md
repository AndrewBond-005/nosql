# Library Events Service

## Стек технологий
- **Backend:** Java 17, Spring Boot 3.2, Maven, Spring Security (HTTP Basic), Spring Data JPA
- **Кэширование:** Spring Cache (ConcurrentMapCacheManager)
- **БД:** PostgreSQL 16 (постоянные данные) и Etcd 3.5 (временные заявки по TTL)
- **Тестирование:** JUnit 5, Testcontainers

## Хранение данных
- **PostgreSQL:** таблицы `events` (каталог), `orders` (заказы), `users` (пользователи), `user_settings` (настройки).
- **Etcd:** ключи `librarytemp:{uuid}` для короткоживущих бронирований.
- 
```text
src/main/java/ru/library/event/
├── config/          настройки Security, Etcd, кэша, начальные данные
├── controller/      REST-эндпоинты
├── service/         бизнес-логика
├── repository/      JPA + Etcd-репозиторий
├── model/           @Entity и DTO
└── exception/       кастомные исключения
```

## Запуск
1. Поднять инфраструктуру через Docker Compose:
   ```bash
   docker compose up -d
   ```
2. Собрать проект и запустить тесты:
   ```bash
   mvn clean package
   ```
3. Запустить приложение:
   ```bash
   java -jar target/library-events-service-1.0.0.jar
   ```

Сервисы доступны по адресам:
- Веб-интерфейс: `http://localhost:8081`
- PostgreSQL: `localhost:5432`
- Etcd: `localhost:2379`

## Основные API эндпоинты
Базовый URL — `http://localhost:8081/api`. Защищены HTTP Basic Auth (кроме `/auth/register` и `/auth/login`).
- `POST /api/auth/register` — регистрация
- `GET /api/events` — каталог книг
- `POST /api/orders?managerId={id}` — оформление заказа
- `POST /api/temp-requests` — создание временной заявки в Etcd
